AI agents in a chat, not a terminal

Aether is an app you install on your own computer. Hand work to an AI in a chat window and answer its approval requests right there. No account needed.

See what the AI is doing without watching a terminal

A chat window, not a terminal

Files the AI read and commands it ran appear as cards. When it asks a question or needs approval, you answer right there.

Want to use it from your phone?By default, Aether opens only on the computer it is installed on. Install Tailscale on the computer and your phone, sign in to the same account, then turn on Use on your phone in Settings to get the same screen in your phone browser. It will not open while the computer is asleep.

Three steps to install

  1. Move the app to Applications

    Open the downloaded file and drag Aether into the Applications folder.

  2. Get past the security warning

    The app is not notarized by Apple, so a security warning appears the first time.

    If it will not open, go to Privacy & Security in System Settings and choose “Open Anyway”.

  3. Initial setup

    When you first open the app, the setup page opens in your browser. Follow it and you are ready to go.

Before you start

Aether does not include an AI tool. Install the one you want to use and sign in first.

Updates

When a new version is out, press Update in Settings under Server info. The app downloads the new version, replaces itself, and reopens. Your conversations and settings are kept, and running sessions stop during the swap.
