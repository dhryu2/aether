폰에서도 쓰고 싶다면기본 설정에서는 설치한 컴퓨터에서만 열립니다. Tailscale 같은 VPN으로 직접 연결하면 폰 브라우저에서도 같은 화면을 쓸 수 있습니다.

설치는 세 단계면 끝납니다

  1. 설치 파일 실행

    다운로드한 파일을 실행합니다. 관리자 권한은 필요 없습니다.

  2. 보안 경고 넘어가기

    아직 코드 서명이 없어서 처음 실행할 때 보안 경고가 나타납니다.

    Windows 파란색 경고 창에서 「추가 정보」를 누른 뒤 「실행」을 누릅니다.

    Mac 열리지 않으면 「시스템 설정」의 「개인정보 보호 및 보안」에서 「그래도 열기」를 누릅니다.

  3. 초기 설정

    설치가 끝나면 브라우저에 초기 설정 화면이 열립니다. 안내를 따라 마치면 바로 쓸 수 있습니다.

사전 준비

Aether에는 AI 도구가 포함되어 있지 않습니다. 사용할 AI 도구를 먼저 설치하고 로그인해 두세요.

업데이트

새 버전이 나오면 설정의 서버 정보에서 업데이트 버튼을 누르세요. 설치를 마치면 Aether가 다시 열립니다. 대화와 설정은 그대로 유지되고, 설치하는 동안 실행 중인 세션은 멈춥니다.
